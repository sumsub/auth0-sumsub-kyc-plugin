# Sumsub KYC Integration for Auth0

The code of the [Sumsub](https://sumsub.com) KYC integration for Auth0, published as open source
per the Auth0 marketplace requirements.

To use the integration, install it from the Auth0 Marketplace:
https://marketplace.auth0.com/integrations/sumsub-kyc-integration
